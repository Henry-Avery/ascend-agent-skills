# Repository scope

Publish selected, reusable Ascend inference and vLLM development workflow skills only. Add a skill by reviewing its complete directory, then inspect every file before publishing. Keep source provenance and licensing clear; distinguish source inspection from runtime validation.

Do not copy private workspace indexes, credentials, account or host details, raw logs, user data, or unrelated skill directories into this repository. A new skill requires an explicit scope decision and a complete-file review before release.
